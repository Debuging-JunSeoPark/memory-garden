# 각 월 정원에서 여는 기억의 책장

사용자가 승인한 후속 순서를 따라 PR #39를 병합하고 각 땅의 책장을 한 기능 PR로 진행한다. 가까이 가서 선반을 연 뒤 책을 고르는 기존 상호작용을 모든 열린 월에 확장한다. 해당 월 우선·다른 월 열람 가능이라는 기존 선택을 따른다.

## 동작

- 모든 열린 땅의 북서쪽 로컬 좌표 (-1.65, -1.65)에 같은 3단·단별 5칸 책장 모델을 둔다. 주변 땅 렌더링 제한은 유지한다.
- 산책 장면에는 안내서와 그 땅의 월별 책만 표시한다. 기록이 없으면 안내서만 둔다. 작은 원경 책장마다 14권을 복제하지 않는다.
- 가까이 가면 현재 땅의 책장을 클릭하거나 Enter로 연다. 다른 땅의 책장은 원격으로 열 수 없고 전체 보기에서는 상호작용하지 않는다.
- 펼쳐진 선반의 첫 칸은 안내서, 월별 책은 해당 월을 먼저, 나머지는 기존 날짜 역순을 유지한다. 다른 연도 기록과 14권 페이지 이동도 유지한다. 책장 진입 때 페이지를 0으로 돌린다.
- 기록이 없는 월은 빈 월별 책을 생성하지 않는다. 안내서와 다른 월 책을 보여 주고 해당 월 기록이 없음을 짧게 표시한다.
- 선반 제목 아래 어느 월의 책장인지 보여 준다. 안내서 자동 실행과 하단 책장 보기 버튼은 추가하지 않는다.
- 책을 덮고 선반으로, 선반을 닫고 원래 땅·캐릭터 위치·산책 구도로 돌아온다. 정적 지도는 기존 전역 책장으로 전체 기록을 조회한다.

## 구현 선택

1. **공유 책장 모델 + 월별 진입 문맥 — 채택.** 기존 선반·안내서·기록 읽기 UI를 재사용하고 여는 순간의 월만 보관한다. 확대 장면은 기존 원점의 전용 무대이므로 카메라를 먼 땅으로 옮길 필요가 없다.
2. 월마다 별도 선반·기록 상태를 소유: 기록 목록과 페이지·선택 상태가 중복되고 동기화 비용이 커진다.
3. 책장 접근 즉시 그달 기록 열기: 선반에서 책을 직접 고르는 사용자 요청과 맞지 않는다.

책장 충돌은 열린 모든 땅으로 평행 이동한다. 접근 판정은 현재 땅 좌표를 기준으로 한다. 책장 열기 콜백은 월 변경에 따라 identity가 바뀌지 않게 유지해 보행 중 키가 지워지는 것을 방지한다. 저장 데이터·이미지·네트워크·패키지·FSD 경계는 변경하지 않는다.

## 검증

각 월 접근 위치의 보행·모델 충돌과 모든 다리 왕복을 검사한다. 우선 월이 목록에 없는 경우, 빈 목록, 15권 이상·다른 연도에서도 기록을 잃지 않는 순서를 확인한다. 브라우저에서는 8월까지 실제 이동해 책장을 열고, 안내서·8월·11월 책을 각각 읽고 8월로 복귀한다. 월별 페이지 초기화와 WebGL 대체 경로도 확인한다. pnpm check·전체 데스크톱/모바일 E2E·독립 리뷰·화면 확인 후 별도 PR과 11월 25일 개발일지를 남긴다.
