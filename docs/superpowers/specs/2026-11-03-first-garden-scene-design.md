# 첫 3D 정원 장면

기존 승인 제품 설계와 사용자가 진행을 요청한 오늘 작업 순서의 3D 범위를 구현한다. Issue #8의 결과물은 로그인 없이 열 수 있는 `/garden` 미리보기이며, 소개 화면에서 이동하고 다시 돌아올 수 있다.

## 구현 방식

작은 흙섬, 잔디, 나무, 돌길, 벤치, 꽃밭을 직접 만든 단순 도형으로 배치한다. 외부 GLTF와 텍스처를 도입하는 방식도 고려했지만 첫 장면에서는 다운로드와 에셋 라이선스 의존성 없이 공간·카메라·오류 경계를 먼저 확인하는 방식을 선택한다. 이는 승인 설계가 개발자에게 맡긴 모델링·색상 세부 결정이다.

- 고정 아이소메트릭 직교 카메라와 창 크기에 맞춘 줌을 사용한다.
- R3F의 demand 렌더링, 제한한 DPR과 그림자 해상도를 사용한다. 자동 움직임과 카메라 전환 애니메이션은 없어 모션 감소 설정에서도 정적인 장면을 유지한다.
- Drei의 ContactShadows는 고정 장면에 맞춰 한 프레임만 계산한다.
- 3D 코드는 클라이언트 전용 동적 import로 분리한다. 서버에서 제품 설명과 로딩 대체 화면을 먼저 전달한다.
- WebGL 초기화 오류와 실행 중 context loss는 정적 SVG 정원 지도와 동일한 장소 설명으로 대체한다. 사용자가 직접 정적 지도를 고를 수도 있다.
- Canvas는 장식적인 공간 미리보기이며, 중요한 설명과 내비게이션은 HTML로 제공한다.

캐릭터 이동, 충돌, 오브젝트 상호작용, 기록 CRUD는 포함하지 않는다. 이번 작은 장면은 `widgets/garden-preview` 안에서 조합하고 추후 실제 도메인이 생기면 엔티티로 분리한다.

## 검증

홈에서 정원으로 이동, 데스크톱·모바일에서 크기 유지, 수동 지도 전환, WebGL 사용 불가, context loss, 모션 감소 환경을 실제 브라우저로 확인한다. 기존 저장소 검사와 단위 테스트를 유지하며 그림자와 모델 외형은 화면으로 검수한다.
