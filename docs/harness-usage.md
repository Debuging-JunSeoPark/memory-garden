# 에이전트 하네스 사용법

## 작업 시작

1. `agents/memories/repo.md`에서 제품 방향과 저장소 규칙을 확인합니다.
2. `agents/memories/session.md`에서 현재 목표, 진행 상태, 장애물을 확인합니다.
3. 관련 스킬이 있다면 `SKILL.md`와 입력·출력 스키마를 함께 읽습니다.
4. Issue의 완료 조건과 충돌하는 기억이 있다면 Issue와 최신 사용자 지시를 우선하고 기억을 갱신합니다.

## 작업 중

- 완료한 결과와 다음 작업만 `session.md`에 간결하게 반영합니다.
- 지속할 아키텍처 결정은 이유와 함께 `repo.md`에 기록합니다.
- 로컬 실험은 `session.local.md`를 사용하고 커밋하지 않습니다.
- 스킬은 스키마 밖 입력을 추측해 실행하지 않고 명시된 실패 상태를 반환합니다.

## 작업 종료

1. 테스트와 저장소 검증 결과를 확인합니다.
2. `session.md`의 완료, 진행 중, 다음, 장애물 섹션을 최신화합니다.
3. 비밀값이나 개인정보가 기억과 로그에 포함되지 않았는지 확인합니다.
4. PR 본문에 사용한 하네스 자동화와 중요한 판단을 기록합니다.

## 새 스킬 추가

`agents/skills/<kebab-case-name>/`에 세 필수 파일을 추가합니다. 입력과 출력은 JSON Schema로 제한하고, `SKILL.md`에 읽기·쓰기 범위, 외부 부작용, 실패 상태를 적습니다. 네트워크나 파일 변경이 필요하면 대상과 이유를 구체적으로 적습니다.
