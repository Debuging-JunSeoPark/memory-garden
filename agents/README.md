# Agent Harness

이 디렉터리는 사람과 코딩 에이전트가 공개된 규칙, 결정, 작업 계약을 공유하기 위한 작은 하네스입니다.

- `memories/`: 저장소의 장기 결정과 현재 진행 상태
- `skills/`: 입력과 출력이 명시된 재사용 작업 계약
- `hooks/`: 허용 목록을 통과한 로컬 자동화
- `server-agent/`: 로컬 작업 위임 API 스캐폴드

하네스는 권한을 새로 부여하지 않습니다. 각 작업은 저장소 규칙과 실행 환경의 기존 권한 안에서만 동작해야 합니다. 구조와 신뢰 경계는 [하네스 문서](../docs/harness.md), 실제 사용 순서는 [사용 가이드](../docs/harness-usage.md)를 참고하세요.
