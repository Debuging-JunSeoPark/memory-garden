# Allowlisted Hooks

훅은 사람이 검토한 `allowlist.json`의 이름으로만 실행합니다.

```bash
pnpm agent:hook -- check-memory
```

`runner.js`는 다음 규칙을 강제합니다.

- Node.js 실행 파일은 현재 프로세스의 정확한 경로를 사용합니다.
- 자식 프로세스는 `shell: false`로 실행합니다.
- 실행할 스크립트, 허용 인자, 제한 시간을 허용 목록에서 읽습니다.
- 셸 메타문자와 등록되지 않은 인자를 실행 전에 거부합니다.
- 제한 시간은 최대 30초이며 초과한 프로세스는 종료합니다.
- 환경은 `PATH`만 전달하고 토큰이나 애플리케이션 환경 변수를 상속하지 않습니다.

새 훅을 추가할 때는 러너 테스트에 성공, 거부, 시간 제한 동작을 추가하고 PR에서 필요한 읽기·쓰기 범위를 설명합니다.
